## 3. 全站文案（英文 EN-CA，可直接落地）

> **写作风格统一约定**：
> - 句长 ≤ 18 词，初中阅读水平
> - 数字用阿拉伯数字（"50 seats"）
> - 美元写 "$2,400/oz"，加拿大投资者通用
> - 不出现 emoji；强调用 `**bold**` / 颜色 / 短线 `—` / 中点 `·`
> - 不出现 "guarantee / promise / risk-free / 100% / make money / get rich"
> - 用 "may / could / potential / opportunity / on our radar / our team is watching" 软化

## 7. 合规与黑页平衡（黑页约束清单）

虽然是黑页（不走 Google/Meta 审核），但仍需避免**法律风险词**。以下是文案审查清单：

### 7.1 严禁出现（任何位置）
- ❌ "guaranteed return / profit / income"
- ❌ "risk-free / no risk / zero risk"
- ❌ "100% / 200% / X% annual return"（**特定的、未来导向的收益率**）
- ❌ "you will make $XX"（未来人称承诺）
- ❌ "registered investment advisor"（除非真实持牌）
- ❌ "insider trading"（用 "insider room / insider list" 可以，不要直接说 trading）

### 7.2 黑页允许（v1 不能用，v2 能用）
- ✅ "Our analyst team" / "Bay Street analysts" / "geologists"
- ✅ "Today's pick" / "Daily alert" / "Insider room"
- ✅ "Only 50 seats" / "9 seats left"
- ✅ "Recent calls" + 用 "reported price action" 描述（**不主张是我们的功劳**）
- ✅ "High conviction" / "On our radar" / "Catalyst expected"
- ✅ "Free for today" / "Invite-only"

### 7.3 软化模板
- "could see significant upside if drill results come in" ✅
- "stock saw triple-digit move following the catalyst" ✅（描述已发生的市场事实）
- "we believe this name is worth watching" ✅
- "potential opportunity in the uranium space" ✅

### 7.4 必备免责（footer 完整保留）

## 9. 实施时给设计 / 工程的关键提示

- **首屏字数控制**：H1 + H2 + 3 利益点 + CTA1 + 紧迫感小字，桌面 1 屏内必须能放下（min-height 100vh）
- **CTA 复现 3 次**：首屏 / Pick Teaser 段 / Seats 段；移动端全宽
- **倒计时 + 席位计数都要"看起来活的"**：JS 每秒刷新；席位数字可在 [38, 47] 区间小幅波动，营造"实时"感（**注意 ≥ 50 永不触发，避免穿帮**）
- **Pick Teaser 卡片**：用 CSS `filter: blur(6px)` + 半透明黑遮罩 + 居中锁图标，blur 不能太狠以保留"看得到一点"的钩子张力
- **Analyst 头像**：4 张照片由 gpt-image 生成（"professional headshot, business casual, neutral background, photorealistic, Canadian"），圆形 96×96，加 1px 金色描边
- **Live Room 模拟气泡**：WhatsApp 风格深绿 `#005C4B` 气泡 + 时间戳右下角，注意时间戳必须比"现在"早几分钟（用 JS 动态生成）
- **入群滚动条**：纯 CSS `@keyframes` 上下滚动，6 条消息循环
- **WhatsApp 按钮配色**：CTA 主色保持金渐变（与品牌一致），WhatsApp 绿仅在 18×18 SVG 图标里点缀，避免页面出现两种主色冲突
