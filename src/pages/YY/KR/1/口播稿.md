## 사용 팁 / 使用提示

### 1. 톤앤매너 / 语调风格
- **전문가 신뢰형 / 专家信任型**: 진지하고 전문적인 톤, 신뢰감 강조 / 严肃专业的语调，强调信任感
- **친근한 스타일 / 亲切风格**: 밝고 친근한 톤, 편안한 느낌 / 明亮亲切的语调，轻松的感觉
- **긴급성 강조형 / 强调紧迫性**: 빠르고 역동적인 톤, 긴박감 조성 / 快速动态的语调，营造紧迫感
- **스토리텔링형 / 故事叙述型**: 서정적이고 감성적인 톤, 공감대 형성 / 抒情感性的语调，形成共鸣

### 2. 촬영 팁 / 拍摄提示
- **시작 / 开始**: 밝은 표정으로 인사 / 用明亮的表情打招呼
- **중간 / 中间**: 핵심 내용 강조 시 손동작 활용 / 强调核心内容时使用手势
- **끝 / 结尾**: 명확한 CTA (Call to Action) 제시 / 明确展示行动号召
- **배경 / 背景**: 전문적이고 깔끔한 환경 / 专业整洁的环境

### 3. 편집 팁 / 剪辑提示
- **자막 / 字幕**: 핵심 키워드 강조 (급등주 분석, 무료, 35% 수익률 등) / 强调核心关键词（暴涨股分析、免费、35%收益率等）
- **BGM / 背景音乐**: 경쾌하고 긍정적인 배경음악 / 轻快积极的背景音乐
- **화면 전환 / 画面转换**: 통계 숫자 등장 시 시각적 효과 / 统计数字出现时使用视觉效果
- **CTA 화면 / 行动号召画面**: 링크와 QR 코드 명확히 표시 / 清晰显示链接和QR码

### 4. 최적 길이 / 最佳长度
- **짧은 버전 / 短版本**: 30-45초 (SNS용) / 30-45秒（用于SNS）
- **표준 버전 / 标准版本**: 45-60초 (YouTube, Facebook) / 45-60秒（YouTube、Facebook）
- **긴 버전 / 长版本**: 60-90초 (상세 설명 필요 시) / 60-90秒（需要详细说明时）

### 5. 핵심 메시지 강조 / 核心信息强调
